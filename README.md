# نظام الحياة الشخصي — Personal Life OS

تطبيق ويب عربي بالكامل (من اليمين إلى اليسار) لإدارة حياتك اليومية: المهام، المشاريع، العادات، الروتين، الخطط اليومية والأسبوعية، المراجعات، والملاحظات — يعمل بالكامل داخل المتصفح دون أي خادم خلفي، وبياناتك تبقى على جهازك.

## المزايا الرئيسية

- **اليوم والأسبوع**: تخطيط يومي مقسّم إلى فترات (صباح، منتصف النهار، عصر، مساء، ليل) مع عرض قائمة وخط زمني، وتخطيط أسبوعي مع مراجعة أسبوعية.
- **المساحات**: تنظيم العناصر في مساحات (حياة، عمل، تعلّم…) مع روابط متعددة المساحات.
- **الوارد (Inbox)**: التقاط سريع للأفكار والمهام ثم معالجتها وتحويلها إلى عناصر منظّمة.
- **المشاريع والمهام والملاحظات**: أنواع عناصر متعددة مع علاقات (مهمة فرعية، يعتمد على، مرتبط) مع كشف الحلقات الدائرية.
- **الروتين ومحرك التكرار**: قواعد تكرار (يومي/أسبوعي/شهري) مع إيقاف مؤقت، استئناف، وإنهاء قبل تاريخ — بتوليد تواريخ خالٍ من أخطاء التوقيت الصيفي.
- **الترفيه والمتابعة**: تتبّع الكتب والأفلام والمسلسلات وغيرها مع شريط تقدّم.
- **ملاحظات العودة**: ملاحظات مؤجلة تعود تلقائيًا في التاريخ المحدد.
- **البحث الفوري**: بحث في كل العناصر مع تمييز النتائج (لوحة المفاتيح ⌘K / Ctrl+K).
- **الاستئناف الذكي**: اقتراحات لاستئناف ما توقف عنده العمل.
- **النسخ الاحتياطي والاستعادة**: تصدير واستيراد ملف نسخة احتياطية موقّعة ببصمة تحقّق (checksum)، مع لقطة أمان قبل الاستعادة وتراجع بعدها.
- **تطبيق ويب تقدمي (PWA)**: يعمل دون اتصال، قابل للتثبيت على الجوال والحاسب.
- **عربي بالكامل**: واجهة RTL، أرقام عربية-هندية، وبرمجيات وسيطة للوقت والتاريخ تتعامل مع التقويم الميلادي بدقة UTC.

> التسجيل يتم بالاسم فقط (بدون بريد أو كلمة مرور) — البيانات محفوظة محليًا في متصفحك عبر IndexedDB، ويمكن تصديرها في أي وقت كملف نسخة احتياطية.

## التقنيات

| الطبقة | التقنية |
| --- | --- |
| الإطار | Next.js 16 (App Router) + React 19 |
| اللغة | TypeScript (وضع صارم، بدون `any`) |
| التنسيق | Tailwind CSS 4 + مكونات shadcn/ui |
| قاعدة البيانات | Dexie (IndexedDB) في المتصفح — 26 جدولًا |
| إدارة الحالة | Zustand + liveQuery من Dexie |
| البحث | MiniSearch |
| الاختبارات | Bun test (91 اختبارًا) |

## البدء السريع

يتطلب [Bun](https://bun.sh) v1.3 أو أحدث (أو Node.js 20+ مع npm):

```bash
# تثبيت الاعتماديات
bun install

# تشغيل بيئة التطوير على المنفذ 3000
bun run dev
```

ثم افتح <http://localhost:3000>.

### أوامر أخرى

| الأمر | الوظيفة |
| --- | --- |
| `bun run dev` | خادم التطوير |
| `bun run build` | بناء نسخة الإنتاج (المستخدمة في Vercel) |
| `bun run build:standalone` | بناء نسخة قائمة بذاتها للتشغيل الذاتي (VPS/Docker) |
| `bun run start` | تشغيل النسخة القائمة بذاتها |
| `bun test` | تشغيل 91 اختبارًا (الخدمات، محرك التكرار، النسخ الاحتياطي، التواريخ، الترجمة) |
| `bun run typecheck` | فحص الأنواع (صارم) |
| `bun run lint` | فحص ESLint |

## النشر على Vercel

الطريقة الأسهل — من GitHub:

1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `personal-life-os`).
2. ارفع الكود إلى المستودع:

```bash
git init
git add .
git commit -m "نظام الحياة الشخصي — الإصدار 1.0.0"
git branch -M main
git remote add origin https://github.com/<اسم-حسابك>/personal-life-os.git
git push -u origin main
```

3. ادخل إلى <https://vercel.com> واضغط **Add New → Project**، ثم اختر المستودع.
4. Vercel سيتعرّف على Next.js تلقائيًا — اترك الإعدادات كما هي (Build Command: `bun run build`، ولا حاجة لأي متغيرات بيئة) واضغط **Deploy**.

أو من الطرفية مباشرة عبر Vercel CLI:

```bash
bunx vercel        # نشر أول مرة
bunx vercel --prod # تحديث النسخة الإنتاجية
```

ملاحظة: لا يحتاج المشروع إلى أي خدمات خارجية أو مفاتيح سرية — كل شيء يعمل في المتصفح، وأي نشر على أي منصة Next.js ثابتة سيعمل مباشرة.

## هيكل المشروع

```
src/
├── app/                  # نقطة الدخول (App Router) — صفحة واحدة SPA
├── components/
│   ├── lifeos/           # شاشات التطبيق (اليوم، الأسبوع، المساحات، الوارد…)
│   └── ui/               # مكونات shadcn/ui
└── lib/lifeos/
    ├── services/         # طبقة الخدمات (عناصر، تخطيط، تكرار، نسخ احتياطي…)
    ├── db.ts             # مخطط Dexie / IndexedDB
    ├── types.ts          # الأنواع المشتركة
    ├── i18n.ts           # الترجمات العربية (~690 مفتاحًا)
    └── dates.ts / prayer.ts / …  # أدوات التاريخ والوقت والأذان
tests/                    # اختبارات Bun (خدمات + محرك تكرار + نسخ احتياطي + تواريخ + ترجمة)
public/                   # الأيقونات و PWA manifest و service worker
```

## البيانات والخصوصية

- كل البيانات تُخزَّن محليًا في IndexedDB داخل متصفحك — لا يغادر أي شيء جهازك.
- النسخ الاحتياطي: من **الإعدادات → النسخ الاحتياطي** يمكنك تصدير ملف JSON موقّع ببصمة تحقّق، واستعادته على أي جهاز.
- قبل أي استعادة تُؤخَذ لقطة أمان تلقائية تتيح التراجع الكامل بعد الاستعادة.
